# Лабораторная работа №1. Создание процессов

БГУ, ФПМИ. Курс «Операционные системы».

## Задача

Консольная программа `Main` и две утилиты — `Creator` и `Reporter`.
Утилиты запускаются из `Main` как отдельные процессы; параметры передаются
через командную строку, данные — через файлы на диске.

Запись файла:

```cpp
struct employee
{
    int num;         // идентификационный номер сотрудника
    char name[10];   // имя сотрудника
    double hours;    // количество отработанных часов
};
```

## Программы

**Creator** — создаёт бинарный файл. Имя файла и количество записей получает
через командную строку, сами записи вводятся с консоли.

```
Creator.exe <бинарный файл> <количество записей>
```

**Reporter** — формирует текстовый отчёт по бинарному файлу. Список сотрудников
упорядочен по табельному номеру, зарплата рассчитывается как часы × оплата за час.

```
Reporter.exe <бинарный файл> <файл отчёта> <оплата за час>
```

**Main** — запрашивает данные с консоли, запускает `Creator` через `CreateProcess`,
дожидается его завершения с помощью `WaitForSingleObject`, выводит содержимое
бинарного файла, затем тем же способом запускает `Reporter` и выводит отчёт.

## Структура

```
Common/     employee.h — общее описание записи для всех трёх программ
Creator/    утилита создания бинарного файла
Reporter/   утилита формирования отчёта
Main/       управляющая программа
```

## Сборка

**Visual Studio 2022.** Открыть `Lab1.sln`, конфигурация Debug x64,
Сборка → Собрать решение. Результат: `x64\Debug\`.

**CMake** (дополнительное задание):

```
cmake -B build
cmake --build build
```

Результат: `build\bin\Debug\`.

Все три исполняемых файла собираются в одну папку — `Main` ищет `Creator.exe`
и `Reporter.exe` рядом с собой.

## Запуск

```
Main.exe
```

Дальше программа запрашивает данные с консоли.

## Окружение

Windows 10, Visual Studio 2022 (MSVC v143), C++17, Windows API.
